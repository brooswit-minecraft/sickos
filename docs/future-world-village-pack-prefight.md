# Future-world village pack prefight (MINECRAFT-332)

Status: **proposal only**.  This document does not add or update any pack
artifact, create a world, change a current world, or authorize release,
deployment, installation, restart, reset, or merge.

The evidence was read from the Modrinth API on 2026-10-13 for Minecraft
1.21.1 / NeoForge candidates.  A Modrinth version record is evidence of an
artifact, not evidence that it generates safely with this pack.

## Baseline and scope

The parent base already pins Tectonic, Lithostitched, and Dynamic Terrain.
Project: Vibrant Journeys is a retained shipped-pack item in the approved
0.53.2 scope; it is not a second installation candidate.  AsYasya's WW1
Weaponry is cancelled and excluded.

All world-generation candidates below are **new-world only**.  They must not
be used to mutate, reset, reposition, or validate against the current world.

## Explicit exclusions and blockers

* **I Need Skating**: no Modrinth project record was found at the requested
  project name, so there is no verified native NeoForge 1.21.1 artifact.
* **Create: Structured**: no Modrinth project record was found at the requested
  project name, so there is no verified native NeoForge 1.21.1 artifact.
* **Immersive Caves**: the returned artifact was
  `immersivecaves-1.4.2-forge-1.20.1.jar`, not NeoForge 1.21.1; exclude.
* **AsYasya's WW1 Weaponry**: cancelled; do not investigate or substitute.
* Tectonic Layers, Structurify, and Scorched Guns all interact with generation
  or structures.  Artifact compatibility is insufficient evidence for their
  combined behavior with Tectonic, Lithostitched, Dynamic Terrain, Integrated
  Villages, or modded biomes.

## Configuration evidence and proposed procedure

No configuration is committed because configuration schemas are generated by
the corresponding installed artifacts and have not been generated in a game
or server for this task.  Do not invent keys or copy an unverified config.

1. In a disposable new-world test profile, use Structurify's documented
   `/structurify dump` command to generate `config/structurify.json`.
2. Review the generated schema for the vanilla village structure-set entry
   and the Integrated Villages entries.  Enable the vanilla village entry;
   do not disable Integrated Villages.  Set a lower, schema-valid village
   spacing and a valid separation lower than spacing for more frequent
   villages.  Do not claim a particular key/value until it appears in that
   generated file.
3. Add every intended Overworld biome (including modded biome IDs) only after
   the dump exposes the relevant per-structure biome list.  Test that vanilla
   and Integrated Villages both remain eligible.
4. For Village Spawn Point, retain the documented fallback behavior:
   `locateVillageTag` should remain `#minecraft:village` unless a tested tag
   is necessary; if changed, keep `keepDefaultVillageTagBackup = true`.

## Required prefight and experimental acceptance

Before any manifest edit, resolve every required dependency to an exact
Minecraft 1.21.1 NeoForge file and hash, run the repository's normal
compatibility/prefight and exact-head CI, and inspect the resulting pack
manifest.  Runtime checks have **not** been performed.

The Tectonic Layers trial is accepted only if a separate disposable new world
can generate and load with Tectonic, Lithostitched, Dynamic Terrain, Amplified
Nether, Structurify, and the selected village configuration; retain vanilla
and Integrated Villages; permit Village Spawn Point to locate a valid village;
and show no startup/crash or obvious terrain/structure-generation failure.
This is an explicit test gate, not a claimed successful generation result.
