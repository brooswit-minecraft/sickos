# Sickos 0.58.0 -- BREAKING

Previous Sickos version: 0.57.1

## Summary

One-time manual modpack update (MINECRAFT-378). Bumps ten compatible mods
to their latest NeoForge/1.21.1 Modrinth release with no behavior-breaking
changes (Balm, Create Aeronautics, Integrated API, Lithostitched, Nature's
Spirit, Power Grid, Sable, Serene Seasons, Supplementaries, Tectonic), and
four self-published "Dynamic" mods whose Modrinth project now 404s, so
they're re-sourced as GitHub-direct pins: Dynamic Terrain 0.22.3 -> 0.28.0,
Dynamic Vehicles 0.55.0 -> 0.59.1, Dynamic Whips 0.7.0 -> 0.9.0 (all three
read in full for destructive/migration language between the old and new
tag; none found beyond ordinary features and fixes), and Dynamic Atmosphere
0.20.3-alpha.1 -> 0.34.0-alpha.1 (BREAKING, see Migration below).

## Migration (Dynamic Atmosphere, cumulative across every intermediate
release between 0.20.3-alpha.1 and 0.34.0-alpha.1)

Each section is the DA GitHub release's own text for the release where that
change actually landed, not the final 0.34.0-alpha.1 release alone (which
is itself just a Phantom-emission/damage patch): v0.21.0-alpha.1 for the
lava/water change, v0.23.0-alpha.1 for the Ender Gas rename/discard,
v0.31.0-alpha.1 for the config-version reset.

### v0.21.0-alpha.1 -- lava/water change
- Lava touching water no longer makes obsidian, cobblestone or stone — it makes magma, and the water is consumed too.
- Obsidian isn't removed from the game by this change — it has moved sideways: lava against packed ice or blue ice now pays out obsidian there instead, in place of the obsidian water+lava used to make.
- Automated stone/cobble/obsidian generation stops working, because the water source is now consumed rather than persisting.
- Breaking a magma block, by any actor or mechanism, now independently rolls a `magma.breakLavaChance` chance (default `0.1`) to leave a lava source at the removed position.

### v0.23.0-alpha.1 -- Ender Gas renamed to Obsidian Powder, no migration
Ender Gas is now Obsidian Powder: the material id `ender_gas` becomes
`obsidian_powder` and every `enderGas.*` config key becomes
`obsidianPowder.*`. There is no migration — saved Ender Gas atmosphere is
discarded and renamed config values reset to their defaults on upgrade.
Client and server must be upgraded together; back up worlds before
upgrading. Existing sources keep their behavior.

### v0.31.0-alpha.1 -- config-version reset
A new internal `configVersion` marker means any config file older than the
mod's current revision (including every pre-this-change file, which counts
as `0`) is preserved as `<name>.toml.bak-<oldVersion>` (collision-safe,
never overwrites an existing backup) and replaced with a freshly regenerated
default file. **This resets that file's configuration; it does not merge
old custom settings into the new defaults.** Checked on both the global
`config/` copy and, for a dedicated server, the per-world
`<world>/serverconfig/` override, on every server start.

## Scope approval

The Ender Gas discard and config resets above are already approved on
MINECRAFT-378 (ticket comment 47958) specifically for the bounded hosted
test-world rollout this release is part of: the user explicitly accepted
config resets and asked for a paired hosted test-world reset. That approval
covers this scope; it is not a blanket exemption from the ordinary backup
and client/server version-matching requirements below.

## Rollout requirements

- Update client and server together; do not mix versions.
- Back up worlds before upgrading.
- This release must ship paired with a reset of the hosted test world and
  a verified, recoverable backup of the old world taken before the reset —
  not as a standalone pack push. See MINECRAFT-378 for the backup-safe
  reset tooling status; `scripts/reset-server-world.py` as it exists today
  has no backup step and must not be run unmodified for this rollout.
- `*.toml.bak-<oldVersion>` files DA itself writes on the server for the
  config-version reset are local-filesystem backups of the *config*, not a
  substitute for the separate *world* backup above.

Herobrine API and Baritone are not distributed in this pack. They remain
optional, separately installed local addons; no API tokens or personal API
configuration are included.
