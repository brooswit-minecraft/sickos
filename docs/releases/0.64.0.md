### Dynamic Vehicles 0.66.0 -> 0.66.2

MINECRAFT-409: Pathfinder now evaluates arrival every server tick
instead of every 20 -- a player/vehicle crossing the target chunk
entirely between widely-spaced samples previously got no credit at all,
not merely delayed credit. Adds a player-visible chat confirmation on
intermediate checkpoints (previously a silent HUD-only update). Fixes
the HUD guidance arrow to rotate relative to the actual rendered camera
yaw instead of the player entity's own yaw, correcting guidance under
any fixed-angle camera view. Decouples the faster arrival cadence from
the existing terminal-retry durability path, which keeps its original
~20-tick cadence.

Being explicit about what this does NOT establish, per the merging
review's own non-blocking caveat: the originally reported "I stopped in
the chunk, nothing happened" report's precise runtime cause remains
unproven. These fixes address demonstrated gaps (a real crossing miss, a
real missing-feedback gap); they are not a confirmed reproduction of
that specific report.
