# Sickos 0.56.0

Category: minor

- Update Dynamic Vehicles to 0.55.0, Dynamic Terrain to 0.22.3, and Dynamic Atmosphere to 0.20.3-alpha.1 on both client and server.
- Vehicles gain persistent health, crash/explosion damage, smoke and fire, flipped-car damage, wreck ejection, and explosions at zero health. Moving vehicles damage and push hostile mobs sideways; creepers detonate on moving-car contact.
- Retune tire erosion around real slip and a 300 kg wheel load, soften collision erosion, and use Sable as the sole vehicle physics implementation. Sable is already included in Sickos.
- Delivery Trading Posts now clear obstructed footprints and fill foundations instead of retrying forever. Placement can replace player builds and containers; choose delivery destinations accordingly.
- Keep detailed atmosphere visible during chunk-boundary rebuilds; include delta-only synchronization and the world-Y=256 rain-cloud default already merged upstream.

The minor bump reflects new gameplay. No world reset or save migration is required. Update client and server together. Preserve existing configs; saved tuning values continue to override changed defaults. Back up worlds before upgrading, and restore a matching backup if rolling back gameplay changes.

Herobrine API and Baritone are not distributed in this pack. They remain optional, separately installed local addons; no API tokens or personal API configuration are included.
