## MINECRAFT-428 version note

MINECRAFT-428 comment 48675 (2026-10-19) sequenced this one-pin Population release to land at 0.68.0, ahead of PR #131 (MINECRAFT-419's mod-additions PR), with #131 rebasing afterward. In practice PR #131 merged into main as 0.68.0 (commit 4fc45c4, 2026-10-19T14:48:51Z) while this branch was still being prepared/rebased on the prior main -- a real instance of the exact two-competing-0.68 race the sequencing comment was trying to avoid. This release is rebased onto that merged main and takes the next free minor, 0.69.0, instead of re-litigating or reverting #131's already-merged, already-released version. This release's own scope stays bounded to the single Dynamic Population pin bump (MINECRAFT-424/425/426/427) and does not touch MINECRAFT-419's merged mod additions or worldgen changes.

Per MINECRAFT-428 comment 48682 (2026-10-19 14:55 UTC), which confirmed this exact collision and superseded 48675's now-impossible 0.68-first sequence: this release's diff relative to the merged 0.68.0 is Population-only -- Immersive Caves, Structurify and client-only YACL (PR #131's published additions) are all preserved unmodified, as is every other existing pin and setting. Tectonic Layers is NOT among them: per MINECRAFT-428 comment 48688 (2026-10-19 15:02 UTC), it was removed from PR #131 after a real startup crash and is absent from the actual published 0.68.0/main index -- confirmed directly against origin/main (mods/tectonic-layers.pw.toml does not exist there; only the pre-existing base mods/tectonic.pw.toml remains).
