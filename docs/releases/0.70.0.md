# Sickos 0.70.0

Updates Dynamic Vehicles from 0.67.0 to the final reviewed 0.75.0 release.
This is a minor release under the pack's 0.x policy because it adds vehicle
and town functionality, rather than only correcting existing behavior.

- Dynamic Towns replace the retired Builder settlement behavior.
- Vehicle suspension settings support damping/bump stops, rear steering,
  tire pressure and anti-dive/anti-squat geometry.
- Engine inertia and clutch coupling include current-contact energy and
  momentum corrections, including reverse and contact-loss cases.
- The Diffuser KIT adds separately configured roll, landing, heading and
  trajectory assists. Stock diffuser settings remain disabled.

The Vehicles artifact is built from `c4e035f5d7efa168a50e048ca06d02e35c922414`.
Its SHA-256 is `ba7981018f99689bbb0cba575e376d0b5347c37beb725d053696d05079431c7b`.
The jar declares Minecraft 1.21.1, NeoForge >=21.1.250, Dynamic Terrain
>=0.28.0 and Sable >=2.0.5; the unchanged pack pins satisfy these requirements.
JLayer 1.0.1 is bundled in the Vehicles jar.

All other mod pins, settings and client/server sides are preserved. Existing
worlds do not require a reset for this pack update. Any separately requested
fresh server world is an operator action with its own backup and deployment
checks, not an operation performed by this pack change.

Herobrine API and Baritone remain excluded from the public pack. Herobrine
0.2.0 is being handled separately by the operator; no API key, API config,
network access change or optional WorldEdit installation is included here.
Existing source-policy and compatibility holds remain in force, including
the exclusion of Tectonic Layers.

Use the same pack version on client and server. Client launch/join and live
server readiness are separate validation gates, not implied by a pack export.
