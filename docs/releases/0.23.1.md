## Gases return in already-explored areas

0.23.0 shipped Dynamic Atmosphere 0.20.0-alpha.1, which left Dust, Ender Gas,
Exhaust, Void Gas and Slime permanently absent in any chunk saved by 0.19.x
or earlier: the old per-material data was preserved on disk but never
readable, and the write path refused to ever replace it. This release pins
Dynamic Atmosphere 0.20.1-alpha.1, which fixes that: a chunk whose stored
tag has a stale version or cell size for one of those five materials now
loads as empty and accumulates new material normally, with the stale tag
replaced on the next save. This includes chunks already re-saved under
0.23.0, since 0.20.0 wrote the preserved tags back verbatim in their old
format. Already-explored areas get these gases again. Old amounts are not
restored; the materials refill from normal production. Newly generated
chunks were never affected. Vapor and Smoke are unaffected throughout.
