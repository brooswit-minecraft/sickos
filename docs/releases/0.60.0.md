# Sickos 0.60.0

Previous Sickos version: 0.59.0

## Summary

One-time manual pack update (MINECRAFT-392), requested after confirming
Backpacks was absent from the pack: adds Dynamic Backpacks (new mod) and
bumps three already-pinned "Dynamic" mods to their latest reviewed,
published releases. Dynamic Population is unchanged at 0.2.0-alpha.1.
Dynamic Battle Axes (0.2.1), Dynamic Despawn (0.3.3), Dynamic Skateboards
(0.3.0), and Dynamic Whips (0.9.0) were independently audited against
their upstream `main` and found already current -- no changes there.
Unfinished work (wallet, new Kings, towns, Pathfinder) is explicitly
excluded from this release regardless of its state.

### Dynamic Backpacks 0.2.0 (new mod)

Craftable material and utility backpacks, including an Emerald Backpack
with a bounded ore-detector scan. Carrying capacity is armor-based: a
worn chest-slot pack protects a portion of the main inventory (Stick Pack
protects half, Leather Backpack and up protect all of it; the hotbar is
never counted or at risk). Moving while occupied main-inventory slots
exceed that protected amount risks dropping a randomly selected whole
stack per spill check (standing still never spills); dropped stacks can
despawn like any other dropped item. This is not per-backpack storage
overflowing -- the backpacks themselves don't hold items; they raise how
much of the player's own inventory is protected.

Upstream provenance: `dynamic-backpacks` v0.2.0, released from reviewed
`main` @ `2eb3e9fd59eef2e4f98c566f0e110d1187f9712e` (PR #2, review
`5554508807`). Jar `dynamicbackpacks-0.2.0.jar`, sha256
`01e8de1108d7a8fe0a99ac9788599460e667dc43a78389b13fab3690e5fa1f66`.

### Dynamic Vehicles 0.59.1 -> 0.61.0

Cumulative across three intermediate releases:
- **v0.60.0**: adds Motorboat, Chopper, and Biplane. These use a new
  `SimpleVehicleEntity` base (not the wheeled `CarEntity`/Sable rigid-body
  stack) with a small, deterministic, per-vehicle movement model run
  identically on server and controlling client -- the same split vanilla's
  `Boat` uses, so no new network payload. Single driver seat only, no new
  textures (vanilla-block silhouettes and placeholder item icons, same
  convention as the existing car roster).
- **v0.60.1**: fixes the Logitech G29 H-pattern shifter's neutral release
  and makes the accelerator gear-aware.
- **v0.61.0**: lava contact and sustained fire now damage a vehicle through
  the existing health system (previously only self-burning at low health
  did); overlapping fire sources share one per-tick damage call so they
  never double-damage, and entering water still extinguishes fire under
  the existing rule.

Upstream provenance: released from reviewed `main` @
`987b2e1f0cd5cb4507491152e2ad6fbb4f559c5d` (PR #166, review
`5564048611`). Jar `dynamicvehicles-0.61.0.jar`, sha256
`e268a9d8053845ae63137169b9d7ae4253902f4b8769c1a5ddb5ace23e0a4d93`.

### Dynamic Terrain 0.28.0 -> 0.28.2

- **v0.28.1**: settles grass as dirt on a successful erosion move. Erosion
  itself stays off by default; set `erosionEnabled = true` in
  `dynamicterrain-server.toml` to opt in.
- **v0.28.2**: generates layered snowy terrain over thin snow cover,
  fixing floating/gapped snow; production-used decision tests added.

Upstream provenance: released from reviewed `main` @
`2017440641cff8c9d383fd6238087ed6dd485ee3` (PR #40, review
`5564037696`). Jar `dynamicterrain-0.28.2.jar`, sha256
`e72fe8d1c0c0ef99c1dc570af66f36d00e794982ef7441f6d46e69ade41b3f31`.

### Dynamic Atmosphere 0.34.0-alpha.1 -> 0.35.0-alpha.1

Cumulative across two intermediate releases:
- **v0.34.1-alpha.1**: atmosphere physics (transport, decay, reactions,
  and the deferred broken-magma lava commit) no longer advances during a
  platform `/tick freeze` -- both tick handlers now gate on
  `runsNormally()`, matching vanilla's own frozen/sprint/step semantics.
- **v0.35.0-alpha.1**: Vapor's rendered opacity now increases as the live
  fog-derived colour it's tinted with darkens (night, dark biomes,
  weather), up to a bounded, configurable cap
  (`vaporDarknessOpacityBoost`, default 3x, range 1-6). Fixes Vapor
  reading as nearly invisible at night. Vapor's colour, density
  distribution, volume shape, LOD, clipping and distance fade are
  unchanged; only alpha is affected, and only for Vapor. No other
  material's rendering changes.

Upstream provenance: released from reviewed `main` @
`908bccab5499c00ddcaaf8a21ba719059fcad3cb` (PR #72, review `5563816281`).
Jar `dynamicatmosphere-0.35.0-alpha.1.jar`, sha256
`2bf637197ae4d89f66b97f9acef632639d9f3d23d03b8acc1fb86c7536f9d1fc`.

## Compatibility

- Requires NeoForge >= 21.1.250 (Backpacks, Terrain, Vehicles); Sickos
  runs 21.1.252, so this is satisfied with no loader bump.
- Dynamic Vehicles 0.61.0 requires Dynamic Terrain >= 0.28.0 and Sable
  >= 2.0.5; both are satisfied by this pack (Terrain 0.28.2, Sable
  2.0.6).
- All four changed/added mods are `side = "both"`.
- No config migration for any of the four: Backpacks is new, and the
  Vehicles/Terrain/Atmosphere bumps introduce no renamed config keys or
  discarded saved state (unlike the Atmosphere 0.34.0-alpha.1 bump in
  0.58.0, which did).

## Disclosed verification gaps -- not falsely claimed as tested

- **Dynamic Vehicles (Motorboat/Chopper/Biplane), two-client multiplayer
  sync**: per PR #164's own test plan, only a single-process `./gradlew
  build` (compile + unit tests) has been run. Entry/exit, controls, and
  two-client position/passenger sync for the three new vehicles have not
  been manually verified in a live client. The existing car roster is
  unaffected by this change (different entity base).
- **Dynamic Atmosphere Vapor opacity, in-game visual verification**: per
  PR #72's own "Visual evidence — gap" section, no day/dusk/night or
  biome-transition screenshots have been captured; this is unit-tested at
  the math/wiring level (`AtmosphereVaporOpacityTest`, 16 tests) but not
  visually confirmed in a live client.

Both gaps are upstream-disclosed, not introduced by this pack bump; they
are carried here rather than resolved, per MINECRAFT-392's own scope.
