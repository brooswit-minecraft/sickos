# Sickos 0.71.0

Updates only Dynamic Vehicles from 0.75.0 to the published 0.76.0 release.
The additive driving dashboard makes this a minor release under the pack's
0.x version policy.

- Tire squeal follows grounded wheelspin and lateral sliding without requiring
  braking. It uses the tire's actual grip budget, stops as slip subsides, and
  excludes airborne free-wheel spin.
- A compact driver-only dashboard displays actual engine RPM and speed in km/h.
  Hide GUI hides the dashboard.

The Vehicles artifact comes from `08bd74ac25ec0f29130c144e6ae62dbaa7032ee6`.
Its SHA-256 is `1a76ea9e55fdf3fb6350f35decbb1cf70e9d13e80d80cbb52d31fae9d9010c5b`.
Embedded version 0.76.0 requires Minecraft 1.21.1, NeoForge >=21.1.250,
Dynamic Terrain >=0.28.0 and Sable >=2.0.5. Existing pack pins satisfy these
requirements; JLayer 1.0.1 remains bundled.

All unrelated pins, settings, side metadata and source-policy/compatibility
holds are preserved. Herobrine API and Baritone remain excluded from the pack.
Existing worlds remain usable; no reset is needed. Use Sickos 0.71.0 on both
client and server for the added synchronized telemetry.

Automated component tests do not replace in-game listening, HUD inspection or
join verification. Those checks are separate from pack export validation.
