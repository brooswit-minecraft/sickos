# Sickos 0.59.0

Previous Sickos version: 0.58.0

## Summary

Adds Dynamic Population (MINECRAFT-386), self-published, pinned to its
first functional release: a persistent, cell-based target-density
population field that reconciles lightweight background villagers
("Fillagers") toward a configurable density, with a Villager King seed
mechanism, village-activity feedback, and an emerald promotion economy.
No other mod is touched: Dynamic Vehicles stays at 0.59.1, and every other
pinned version is unchanged.

Upstream provenance: `dynamic-population` v0.2.0-alpha.1, released from
reviewed `main` @ `4183c7b165d369bb5d842b8c20065dc1f7472527` (see
MINECRAFT-386 for the full upstream release-provenance trail). Jar
`dynamicpopulation-0.2.0-alpha.1.jar`, sha256
`b02f4aa472dec991bcd0c89f4a5238b1e4489bdb933e5fcad0f14662dd3618c4`.

## Compatibility

- Requires NeoForge >= 21.1.250; Sickos runs 21.1.252, so this is satisfied
  with no loader bump.
- `side = "both"`: the mod registers client-side Fillager (nitwit) rendering
  in addition to server-side logic.
- No config migration: this is a new mod with no prior Sickos config to
  migrate, and introduces no change to any other mod's config or world
  format.

## Known limitations (carried from upstream)

- Villager job-site work (composting, smithing, etc.) is not wired into
  activity feedback -- no accessible NeoForge/vanilla event exists for it
  as of NeoForge 21.1.250/251.
- Propagation and the Villager King simulate the Overworld only (V1).
- No Modrinth publishing is wired for `dynamic-population` -- this pack
  pins the GitHub Release asset directly, the same way Dynamic Vehicles,
  Dynamic Terrain, and Dynamic Whips are already pinned.

## Verification performed

- `make check` -- `packwiz refresh` produces no further diff.
- `make build` -- exports cleanly; Dynamic Population's jar is present in
  the manifest alongside all other pinned mods.
- `make verify-runtime` -- exported mrpack and a materialized real
  NeoForge 21.1.252 server agree; Quark's own metadata range is satisfied.
- A disposable full-pack server boot: a real NeoForge 21.1.252 dedicated
  server with every server-eligible mod installed (including Dynamic
  Population) reached `Done (...)!`, Dynamic Population and Dynamic
  Vehicles both appear correctly in the mod list, and the server shut down
  cleanly (exit code 0) on `stop`.

## Rollout requirements

- Update client and server together; do not mix versions (new mod --
  mismatched installs will desync, not merely miss content).
- No world reset or backup is required: this adds a new mod with no save
  data format changes.
