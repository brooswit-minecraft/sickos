# Sickos 0.65.0

Previous Sickos version: 0.64.0

## Summary

Release batch MINECRAFT-415: exactly one planned pin, Dynamic Vehicles
0.66.2 -> 0.67.0, carrying the shared Dispatcher/Pathfinder navigation UI
from MINECRAFT-411. Dynamic Population stays at 0.3.0-alpha.1 and
Isometric Camera stays at 0.3.0 (MINECRAFT-408's focus-anchor correction
remains open, unmerged, and deliberately excluded). All other pins are
unchanged.

### Dynamic Vehicles 0.66.2 -> 0.67.0

MINECRAFT-411: Pathfinder's checkpoint HUD now reuses Dispatcher's
`ContractWaypointOverlay`/`WaypointMarkerLayout` presentation -- an
actual-camera-projected marker with off-screen edge clamping, distance
readout, and compact dark backing -- instead of the old fixed-corner
arrow/count/countdown overlay. Dispatcher's threat coloring and the
`ClientConfig.showLegacyContractHud` toggle are untouched; the default
Pathfinder corner HUD is suppressed now that the shared marker covers
checkpoint count, countdown, and next-target feedback. Server-authoritative
checkpoint order, the 16x16 chunk/any-Y predicate, dimension checks,
expiry/death handling, saved routes across relogin, every-tick arrival,
and exactly-once rewards from MINECRAFT-409/PR #175 are preserved; no new
gating was introduced.

### Unchanged / explicitly excluded

- Dynamic Population 0.3.0-alpha.1: unchanged. MINECRAFT-390's disclosed
  gameplay-acceptance gaps from the 0.64.0 release remain open and
  unverified; this release does not touch Population and makes no new
  claim about them.
- Isometric Camera 0.3.0: unchanged. The MINECRAFT-408 16-block/-4
  focus-anchor correction is still an open, unmerged PR under re-review
  and is deliberately excluded.
- Camera (408), boat (410), drivetrain (395), and towns (388) work
  remains unfinished and is not included; no silent additions.
- All other pins (Backpacks, Atmosphere, Terrain, Battle Axes, Despawn,
  Skateboards, Whips, and the rest) are unchanged.

## Rollout

Normal release process: this PR, once reviewed and green on CI, merges
to `main`; `release.yml` cuts the GitHub release, publishes to Modrinth,
and triggers hosted deployment per the repo's standard chain. Per
MINECRAFT-415, root coordinates the immutable pack/hash handoff for any
client-side install and collects the server-compatibility and client
receipts; this document does not assert those receipts exist yet.
