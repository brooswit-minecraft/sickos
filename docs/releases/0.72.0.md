# Sickos 0.72.0

Updates only Dynamic Vehicles from 0.76.0 to the published 0.77.0 release.
The additive vehicle features make this a minor release under the pack's
0.x version policy.

- Per-car traction control and ABS controls, disabled by stock defaults.
- Rally Car and per-vehicle FWD, configurable 4WD and asymmetric AWD layouts.
- Configurable loaded-wheel dust, severe-crash block breaking and throttle exhaust.
- Configurable travel-side motorboat lift and shared car/boat driver input and
  forward chase-camera support.

The Vehicles artifact comes from `77c0bb6ebc3b954b09cce859fa2ff25f02de9c1e`.
Its SHA-256 is `102bd30a457e284f98ae2fcc000667214e7511a91e06a765d92d1e41437ca228`.
Embedded version 0.77.0 requires Minecraft 1.21.1, NeoForge >=21.1.250,
Dynamic Terrain >=0.28.0 and Sable >=2.0.5 on both sides. Existing pack pins
satisfy these requirements.

All unrelated pins, settings and side metadata are preserved. Existing worlds
remain usable; no reset or manual migration is required. Use Sickos 0.72.0 on
both client and server. Vehicle behavior changes include the documented drivetrain
layouts and configurable crash block destruction.

Upstream validation includes build/unit tests, 277 GameTests and software-rendered
real-client acceptance on the reviewed source head. Those checks do not establish
physical wheel behavior, visual quality or launch/join acceptance for this exported
pack. Pack validation and hosted deployment are reported separately.
