# Sickos 0.61.0

Previous Sickos version: 0.60.0

## Summary

Approved named release batch (MINECRAFT-400, user approval "cut it" at
2026-10-18 19:26 UTC): Dynamic Backpacks wallet, Dynamic Vehicles
Pathfinder + delivery-placement fix, Dynamic Atmosphere sandier Dust +
sun/moon directional tint, and the new client-only Isometric Camera.
Explicitly excludes the unfinished Dynamic Vehicles radio feature
(MINECRAFT-394), the unfinished superflat garage dimension
(MINECRAFT-397), and faction Kings/population combat (MINECRAFT-390),
regardless of their current state upstream.

### Dynamic Vehicles 0.61.0 -> 0.63.1

Two changes, in order:
- **MINECRAFT-393**: a delivery destination now places only a dispatch
  board and villager, instead of a full structure, with board-cell and
  villager-clearance validation added on review.
- **MINECRAFT-379**: Pathfinder's regional checkpoint-circuit durability
  check now fails closed when the async IO-worker crashes, rather than
  treating a crashed check as "no damage found." Includes a real
  `noCollision`-based fence/wall landing-clearance fix with GameTests,
  reviewed through three rounds (CHANGES_REQUESTED x2, then APPROVED @
  `879d7a5`).

Deliberately stops at v0.63.1. Newer releases exist on this repo
(v0.64.0, v0.65.0, v0.65.1) but carry the vehicle radio feature
(MINECRAFT-394, merged to `main` 2026-10-18 19:28 UTC) and the still-open
superflat garage PR #169 (MINECRAFT-397) -- both explicitly out of scope
for this batch per the ticket. Confirmed directly against the repo:
`git merge-base --is-ancestor <radio-merge-sha> v0.63.1` and the same for
the garage PR's head both return "not an ancestor."

Upstream provenance: released from reviewed `main` @

### Dynamic Atmosphere 0.35.0-alpha.1 -> 0.36.0-alpha.1

Cumulative across two intermediate releases:
- **v0.35.1-alpha.1** (MINECRAFT-398): Dust's default colour moves from
  `0x8B4513` (saddle brown) to `0xD2B48C` (tan), a sandier hue. This
  changes only the SPEC default -- a client config generated under the
  old default (e.g. `dustColor=9127187` / `0x8B4513`) keeps that value
  until the line is edited or the file is regenerated. **Not touched
  here**: no config reset or override performed by this release; flagged
  for the separate client-side owner to handle the narrow default
  migration without disturbing unrelated settings.
- **v0.36.0-alpha.1** (MINECRAFT-399): every atmospheric material (Vapor,
  Smoke, Dust, Void Gas, Exhaust, Slime, Obsidian Powder, Zombie Fog,
  Nether Gas, Glow Gas, Nether Fog) now blends toward a configurable
  sun/moon colour by viewing angle, bounded by `celestialTintMaxStrength`
  (default 0.35) so a material never loses its own colour identity.
  Respects vanilla sun/moon visibility (horizon, dimension, rain) and
  terrain/building occlusion.

Upstream provenance: released from reviewed `main` @
`2d2a6d2b9a1fd14a6a4d36183d8ef920c8332e6d` (PR #74). Jar
`dynamicatmosphere-0.36.0-alpha.1.jar`, sha256
`1d15948c9056dd8ce9e70bff7a9653e57e17953f9e7e2e151f51154326b8bbf2`
(independently verified against the downloaded artifact).

### Isometric Camera 0.1.0 (new mod, client-only)

MINECRAFT-376/MINECRAFT-396. A fourth F5 perspective: a fixed-angle,
Minecraft Dungeons-like isometric view with screen-relative WASD movement
(W/A/S/D always move up/down/left/right on screen regardless of
mouse-look). Pressing F5 again from third-person front enters it; F5
again returns to first person. Every other perspective and its controls
are untouched.

Client-only: pinned `side = "client"` in packwiz, confirmed `server:
"unsupported"` in the exported mrpack manifest. A server running this
pack needs no change to support it; a client without it simply does not
offer the new perspective.

Upstream provenance: released from reviewed `main` @
`45157d9b5bcbe34747e0212b98c19ea3838838bd` (PR #1). Jar
`isometriccamera-0.1.0.jar`, sha256
`262eee56ebb47e594c670c406a1e3296bc1c8e928c9de935ba75dc7460259b84`
(independently verified against the downloaded artifact).
